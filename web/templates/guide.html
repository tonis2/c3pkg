Install guide

Find a library on this site, paste one line, run one command.

Before you start

You need c3c 0.8.6 or newer. To check your version, run:

{{hl "bash" "c3c --version"}}

Projects made with c3c init are ready to go. Other projects need "dependency-search-paths": ["lib"] in project.json.

Add a library

Copy the line from the library's page into dependencies in project.json:

{{lineBlock (printf `"dependencies": [ %s ],` (installLine .Base "tonis2" "image" "0.0.6"))}}

Then download it and build:

{{hl "bash" `c3c project fetch image c3c build`}}

For several libraries, name them all:

{{hl "bash" "c3c project fetch image toml"}}

Update a library

Change the version in project.json, then name the library. Plain c3c project fetch only checks that a library is there, not which version it is.

{{hl "bash" "c3c project fetch image"}}

Lock to a checksum

Add the checksum to the line, and c3c refuses any file that doesn't match. Every package page has this line under "Lock to a checksum".

{{lineBlock (lockedLine .Base "tonis2" "image" "0.0.6" "0b8e4f00245553ae153a5996a488a5a0b0a214cf58f99be48fa1bf0fbe5e7a2c")}}

Libraries that need other libraries

c3c only builds libraries listed in your project. When a library needs others, its page lists them under Dependencies. Click each one to find it, then add it the same way.

Try a library without a project

This downloads a library into the current folder:

{{hl "bash" (printf "c3c --fetch-url %s fetch tonis2/image" .Base)}}

Don't use this in a project you share. It saves only the name in project.json, and that can't be found again on another machine.

Troubleshooting

c3c saysWhat to do
Could not connect to serverThe line has no URL, so c3c tried localhost:8080. Copy the full line from the package page.
failed to fetch the library listproject.json has only the name. Replace it with the full line from the package page.
All dependencies are installedSeen after changing a version? Name the library: c3c project fetch image
Required library 'x' could not be foundAdd x to dependencies and fetch it. c3c only builds libraries listed in your project.
is not a dependency of the projectAdd the line to dependencies first.
